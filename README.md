# Day 75 – Java Collection

##  Description

This program uses **ArrayList** to store integers and finds the maximum element from the collection.

##  Concepts Used

* Java
* ArrayList
* Collection Framework
* Scanner
* For-each Loop

##  Sample Input

```text
5
10 25 7 40 15
```

##  Sample Output

```text
40
```

##  Learning

Learned how to store elements in an ArrayList and find the maximum value using Java Collection.
